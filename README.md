# 👑 Creator Hero Bot

Telegram-бот для дружеского челленджа: участники публикуют по одному посту в день, отправляют отчёт с хештегом #пост, получают напоминания и отрабатывают пропуски. Бот работает в одной группе через long polling, без публичного HTTP-порта.

## Текущий запуск

- Бот: @content_challenger_bot.
- Рабочий экземпляр: VPS, SSH-алиас creator-hero-vps.
- Каталог: /home/ubuntu/coding-projects/creator-hero-bot.
- Контейнер: creator-bot; данные SQLite: Docker volume creator-bot-data.
- Локальный контейнер остановлен. Для одного токена должен работать один polling-процесс.
- На VPS настроен ежедневный бэкап в 04:00 МСК. Копию на компьютер можно забрать скриптом ниже.

Текущий статус процесса проверяйте командой:

    ssh creator-hero-vps 'docker inspect --format "{{.State.Status}} {{.State.Health.Status}} {{.RestartCount}}" creator-bot'

Подробная процедура деплоя и восстановления — в docs/deploy.md.

## Как пользоваться

1. Организатор создаёт группу и добавляет бота администратором с правами приглашать и блокировать участников.
2. Организатор отправляет в группе /init_stream. Бот привязывает группу и создаёт общую ссылку.
3. Организатор пишет боту в личку /approve @username.
4. Друг пишет боту /start, получает ссылку и вступает в группу.
5. Каждый день участник отправляет в группу #пост: ссылку на публикацию, форвард или текст от 400 символов.

Вход остаётся дружеским. Если по общей ссылке зайдёт человек вне списка, бот сообщит организатору, но не удалит гостя. Гость не попадает в статистику и не получает штрафов. После первой привязки запись участника закрепляется за его Telegram ID.

### Команды организатора

| Команда | Где | Действие |
| --- | --- | --- |
| /init_stream | Группа | Привязать группу и создать ссылку |
| /approve @username | Личка бота | Добавить друга или вернуть кикнутого |
| /revoke @username | Личка бота | Убрать из списка ещё не вступившего |
| /stats | Личка бота | Показать статистику потока |

## Правила и расписание

По умолчанию отчёт принимается до 23:59 по Europe/Moscow. За пропуск бот выставляет штраф: донат 500 ₽ или видео с 30 бёрпи. Сообщение с #штраф закрывает открытые штрафы; факт доната бот не проверяет. Через 24 часа без отработки участника удаляют из группы. Самостоятельный выход ставит участие на паузу, но уже открытые штрафы сохраняются.

| Время потока | Задание |
| --- | --- |
| 21:00 | Напомнить тем, кто ещё не отправил #пост |
| 00:00 | Опубликовать дайджест и выставить штрафы за вчера |
| 20:00 | Напомнить об открытых штрафах |
| 00:05 | Удалить участников с просроченным штрафом |

Время, длина поста и размер штрафа задаются переменными из .env.example. Отредактированное сообщение не пересчитывается — отчёт нужно отправить заново.

## Разработка

Для локального запуска скопируйте .env.example в .env и задайте BOT_TOKEN и OWNER_TG_ID. Файл .env исключён из Git; токен не размещают в README, командах и логах.

    python3.12 -m venv .venv
    source .venv/bin/activate
    pip install -e '.[dev]'
    pytest -q
    ruff check .

Для проверки контейнера:

    docker compose build
    docker compose ps

Пока бот работает на VPS, не запускайте локальный docker compose up с тем же токеном.

## Деплой и бэкапы

Код отправляется на VPS через SSH и rsync; GitHub для этого не требуется. Команда ниже только передаёт файлы, сохраняя серверные .env и backups/:

    ./scripts/deploy.sh creator-hero-vps coding-projects/creator-hero-bot --stage-only

Для обновления контейнера после передачи кода:

    ssh creator-hero-vps 'cd ~/coding-projects/creator-hero-bot && docker compose up -d --build'

Для проверки работы и скачивания отдельной копии БД на компьютер:

    ssh creator-hero-vps 'cd ~/coding-projects/creator-hero-bot && docker compose ps'
    ssh creator-hero-vps 'cd ~/coding-projects/creator-hero-bot && docker compose logs --tail=100 bot'
    ./scripts/backup.sh creator-hero-vps

Миграции Alembic применяются при старте контейнера. База хранится в named volume и сохраняется при пересборке образа. Перед переносом или восстановлением данных следуйте docs/deploy.md.

## Где что находится

- bot/handlers — команды и события Telegram.
- bot/services — правила челленджа, отчёты, онбординг и тексты.
- bot/scheduler/jobs.py — расписание и восстановление пропущенного закрытия дней.
- bot/db — модели и запросы SQLite; alembic/versions — миграции.
- tests/ — тесты; .github/workflows/ci.yml — CI, который заработает после публикации репозитория на GitHub.
- docs/architecture.md — модель данных и поведение; docs/deploy.md — операции на VPS; docs/plan.md — будущие функции.
