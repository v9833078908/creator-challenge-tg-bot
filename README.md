# 👑 Creator Hero Bot

Telegram-бот ежедневного контент-челленджа: участники пишут по посту в день,
бот считает отчёты `#пост`, напоминает о дедлайне, выставляет штрафы и кикает просрочивших.
Механика — как у Content Hero, брендинг и тексты — свои.

## Быстрый старт (Docker)

1. Создайте бота у @BotFather, узнайте свой id у @userinfobot.
2. `cp .env.example .env` — впишите `BOT_TOKEN` и `OWNER_TG_ID`.
3. Создайте группу, добавьте бота, сделайте его **админом** (нужно для инвайт-ссылки и кика).
4. `docker compose up -d --build` — образ и контейнер называются **`creator-bot`** (видно в Docker Desktop), данные — в volume `creator-bot-data`.
5. В группе: `/init_stream` — бот привяжет чат и создаст бессрочную инвайт-ссылку.
6. В личке боту: `/approve @username` для каждого участника.
7. Участник пишет боту `/start` в личку → получает ссылку → вступает → он в игре.

Вход остаётся дружеским: ссылка общая. Если по ней войдёт человек вне списка,
бот не удалит его, а напишет владельцу в личку. Такой гость не получает
обязательств и не попадает в статистику. После первой привязки участник
определяется по Telegram ID, поэтому смена `@username` не отдаст его место другому.

> Пока в `.env` стоит заглушка токена, контейнер будет перезапускаться с `Unauthorized` — это нормально.
> Впишите настоящий токен и сделайте `docker compose up -d` (без `--build`) — бот поднимется.

Деплой на VPS: `docs/deploy.md` (+ скрипты `scripts/deploy.sh`, `scripts/backup.sh`).

## Правила челленджа (дефолты, всё конфигурируется через .env)

- Каждый день до **23:59 МСК** — `#пост` в группу: ссылка, форвард из канала или текст от 400 символов.
- Пропустил день → **штраф**: донат 500 ₽ или видео 30 бёрпи. Отработка — сообщение с `#штраф` (24 часа).
- Просрочил штраф → **кик**. Вернуться — только через повторный `/approve` владельца.
- Выйти из чата можно в любой момент (пауза без новых штрафов), вернуться — по той же ссылке.
  Открытые штрафы при выходе **не сгорают** — после возврата даётся ещё 24 часа на отработку.
- Отредактированные сообщения не засчитываются (античит) — присылайте отчёт заново.
- Значение `REPORT_DEADLINE` действительно ограничивает приём отчётов;
  сообщения после указанной минуты не засчитываются за этот день.

## Расписание бота

| Время | Что делает |
|---|---|
| 21:00 | напоминает в группе, кто ещё не сдал `#пост` |
| 00:00 | `#дайджест`: кто сдал, кто получил штраф |
| 20:00 | напоминает штрафникам, что до кика осталось мало |
| 00:05 | кикает просрочивших штрафы |

## Локальная разработка

```bash
python3 -m venv .venv && source .venv/bin/activate
pip install -e ".[dev]"
pytest
ruff check .
alembic upgrade head   # применить миграции вручную (бот делает это сам при старте)
BOT_TOKEN=... OWNER_TG_ID=... python -m bot
```

## Команды владельца

| Команда | Где | Что делает |
|---|---|---|
| `/init_stream` | в группе | создать поток, привязать чат, сгенерировать инвайт-ссылку, запустить расписание |
| `/approve @username` | личка | добавить в whitelist / вернуть кикнутого (unban + сброс штрафов) |
| `/revoke @username` | личка | убрать из whitelist (только для ещё не вступивших) |
| `/stats` | личка | статистика: активные, сдавшие сегодня, открытые штрафы, кикнутые |

## Структура

```
bot/
├── __main__.py       # вход: миграции → планировщик → polling
├── config.py         # все правила — через env (.env)
├── handlers/         # dm.py (личка), admin.py (владелец), group.py (чат, #пост/#штраф)
├── services/         # challenge.py (отчёты), digest.py (штрафы/даджест/статистика),
│                     # onboarding.py (статусы), reports.py (валидация), texts.py (все тексты)
├── db/               # models.py, repo.py, engine.py
└── scheduler/jobs.py # 21:00 напоминание, 00:00 дайджест+штрафы, 20:00 штрафникам, 00:05 кик
tests/                # pytest + pytest-asyncio (in-memory SQLite)
alembic/              # миграции (применяются автоматически при старте бота)
```
