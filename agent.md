# Работа агента над Creator Hero Bot

Creator Hero Bot — самостоятельный проект Telegram-бота для ежедневного контент-челленджа. В публичных описаниях объясняйте его собственные задачи, возможности и ограничения.

## Перед изменениями

1. Прочитайте [AGENTS.md](AGENTS.md): это основной файл правил репозитория. Этот документ служит точкой входа и не заменяет его.
2. При изменении поведения прочитайте [docs/architecture.md](docs/architecture.md): там описаны правила участия, состояния, привязка Telegram ID и идемпотентность.
3. Перед деплоем, миграцией или работой с данными прочитайте [docs/deploy.md](docs/deploy.md): там описаны резервное копирование, переключение и восстановление.

## Границы работы

- Сохраняйте уже сделанные пользователем изменения; меняйте только согласованную область.
- Для описания текущего поведения опирайтесь на код и действующие настройки, а не на старые планы и отчёты выкатки.
- Секреты, списки участников, SQLite и эксплуатационные отчёты остаются вне публичного репозитория. Исключения заданы в `.gitignore` и `.dockerignore`.
- Разделяйте проверку кода и действия с рабочим ботом: запуск тестов или сборка образа сами по себе не разрешают запуск второго polling-процесса.
- При публикации отправляйте только выбранную ветку. Локальные служебные refs и снимки рабочего каталога не предназначены для GitHub.

## Критерий завершения

Изменение завершено, когда затронутые сценарии проверены, документация соответствует поведению и выполнены обязательные проверки из `AGENTS.md`. В результате отдельно укажите локальные проверки, действия на рабочем сервере и то, что требует реального взаимодействия в Telegram. Не выдавайте непроверенное поведение за подтверждённое.
