## Риски и решения
| Риск | Решение |
|---|---|
| Edited-сообщения не ловим | Осознанно (античит оригинала); подсказка пользователю в тексте бота |
| Падение бота в 00:00 | Джобы идемпотентны (повторный прогон без дублей); догонялки нет по решению — пропущенное расписание пропущено, как у оригинала |
| Часовые пояса участников | Одна TZ челленджа (МСК), как у оригинала |
| Тексты уроков — чужой контент | Только свои тексты/рерайт, структура и механика — копируем |
| SQLite под нагрузкой | При >3–5 потоках — миграция на Postgres (заложено в архитектуру) |
