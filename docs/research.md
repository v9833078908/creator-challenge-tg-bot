# Ресёрч: Content Hero (contenthero.me) — как устроен оригинал

> Источники: сайт contenthero.me, экспорт группового чата `ChatExport_2026-09-20` («👑 33+ | Content Hero», 447 сообщений, 01.08–30.08.2025), экспорт лички с ботом `ChatExport_2026-09-20 (1)` (74 сообщения, 2023–2026).

## 1. Продукт

Ежедневный платный контент-челлендж «пиши по посту в день». Автор — Вадик Михалёв (экосистема One Hero). Разовый платёж (на момент ресёрча 16 800 ₽), бессрочное участие. Группы ~20 человек, деление по аудитории: 0–100 и 100+ подписчиков. 30 000+ участников с 2018, 49 уроков, средняя дистанция участника 90+ дней.

## 2. Игровая механика (то, что клонируем)

- Каждый день до **23:59 МСК** участник отправляет в группу `#пост`: ссылку на пост, форвард из своего канала или текст (минимум **400 символов**). Публиковать можно куда угодно (TG/IG/YouTube/личные заметки).
- Бот мгновенно отвечает **реплаем**: «№k из N» + эмодзи дня (эмодзи меняется каждый день: ☘️, 🙌, ✊, 🌋, 🍩…).
- Не сдал → **штраф**: донат 500 ₽ с квитанцией или видео 30 бёрпи. Отработка = сообщение с `#штраф` в группу. Бот отвечает «должок списан, спасибо ✨».
- Не отработал штраф за 24 часа → **автокик** из группы.
- **Отпуск**: до 7 дней, раз в месяц — участник выходит из чата сам, предупредив группу.
- Возврат после вылета — платный (у оригинала 12 900 ₽) — у нас вне v1.

### Расписание бота в группе (детерминированное)

| Время | Событие |
|---|---|
| 00:00 | `#дайджест`: участников N, ✅ выполнили (список), 💥 штраф (список) |
| ~20:00 | Предупреждение штрафникам: «не отработаете сегодня — кик» |
| ~21:00 | Напоминание не сдавшим: «скоро полночь, ждём отчётов от …» |
| мгновенно | Реплай «№k из N + эмодзи» на каждый `#пост`; подтверждение на `#штраф` |

### Сознательные ограничения оригинала (копируем как античит)

- Отредактированные сообщения не засчитываются («сорян, не умею ещё») — нельзя сдать пустышку и дописать потом.
- Если бот «не понял» отчёт — просит отправить ещё раз с правильным хештегом.
- Проверки факта доната за штраф нет — засчитывается по хештегу.

## 3. Личка бота (в v1 — частично)

- `/start` → приветствие + инвайт-ссылка в группу потока.
- Каждое утро **08:00 МСК** — обучающий урок (v1.1, не v1).
- 20:00 — напоминание о штрафе в личку (v1.1).
- Тон: на «ты», фамильярный, игровой, с самоиронией («мне оч не хочетсяяя это делать 😭», «в моей электронной душе»).

## 4. Обучающие уроки (вторая итерация оригинала)

Шаблон поста из 5 блоков:
1. Шапка жирным: `👑 35.35 | Content Hero`
2. Рубрика: `📚 Новый урок`
3. Название жирным с эмодзи: `💭 Выгрузка мыслей`
4. Тизер — 1–4 коротких абзаца
5. `🔗 Читать далее...` — ссылка на полный текст (у оригинала — свой сайт через трекинг-кликов Make.com)

Каденция: ежедневно 08:00 МСК, первый урок — в день активации. Примеры уроков 2-й итерации: «Выгрузка мыслей», «Телеграм-гигиена (первые 50 подписчиков)», «Запасные аэродромы», «Лоскутное одеяло опыта», «Настройки канала для чайников», «Лёгкая атлетика».

**Правовая оговорка:** тексты уроков — авторский контент Content Hero. Берём структуру и темы, тексты — свой рерайт.

## 5. Наша адаптация — Creator Hero

- Название: **Creator Hero**; брендинг и все тексты бота — свои, в похожем тоне.
- Аудитория v1: друзья, **одна группа**; архитектура — мультипоточная с нуля (масштабирование без переписывания).
- Скоуп v1: трекинг `#пост`/`#штраф`, подтверждения, дайджест, напоминания, штрафы, автокик. **Без** онбординга через личку, уроков и оплаты (v1.1+).
- Все правила — конфигурируемые (дедлайн, мин. длина, размер штрафа, лимит отпуска).
