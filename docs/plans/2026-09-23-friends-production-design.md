# Надёжный запуск для друзей

## Решение

Группа остаётся дружеской: общая ссылка и свободный вход сохраняются. Незнакомого
вошедшего бот не удаляет, а сообщает организатору. Правила отчётов, штрафов и
автоматического кика не меняются.

## Безопасность и идентичность

`@username` нужен только для первой привязки одобренной записи. После привязки
запись принадлежит неизменному Telegram ID. Новый владелец старого username не
получает статус участника. Бот уведомляет владельца о неизвестном вошедшем и
не включает его в статистику или штрафы.

## Время и восстановление

Все расчёты локальной даты исходят из UTC с явным часовым поясом. Telegram
updates не сбрасываются при рестарте. Закрытие дня записывает факт выполнения
в БД; при простое пропущенные дни обрабатываются после восстановления событий.
Чтобы не назначить неверный штраф из-за неполной истории участников, для
догоняющего закрытия используется только подтверждённая история членства.

## Эксплуатация

SQLite копируется через backup API, а восстановление проверяется на тестовой
копии. Healthcheck проверяет состояние процесса и расписания. Релиз проверяют
тесты, lint, сборка образа и тестовая миграция. Документация описывает запуск,
обновление и восстановление.
